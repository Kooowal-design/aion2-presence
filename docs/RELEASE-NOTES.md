Public beta for Windows · English / Polski

## New in 0.2.0-beta.13

- Sorcerer now uses an **open spellbook** icon, matching the class weapon. The Discord image URL is versioned so clients can fetch the new artwork.
- Updated class-artwork illustrations in both the English and Polish README.
- Includes the beta.12 correction: idle activity reads **AION 2 - In game** in the profile and Activity-only member-list mode. Auto still shows selected stats while idle; the fixed game-name mode remains **AION 2**.
- Recognized activity names and the capture engine are unchanged. Normal in-game status has no small activity badge.

Download **Aion2Presence-Setup.exe**, or choose **Download and install** in the app. You can update directly to this version. For a manual update, exit the previous copy from its system tray menu first. Settings and the installation folder are retained.

**Polski:** Sorcerer ma teraz ikonę **otwartej księgi**. Plansze klas w opisach EN i PL również zostały poprawione. Wydanie zawiera tekst zwykłej aktywności **AION 2 - In game** z beta.12. Można od razu zainstalować tę wersję; ustawienia i folder instalacji zostają zachowane.

Npcap, AION 2 and Discord desktop are required on the same computer. The executable remains unsigned. Matching source, notices and SHA-256 checksums are attached.
