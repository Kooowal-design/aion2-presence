## Optional ShadowPC diagnostic

**Aion2Presence-Crafting-Diagnostic.zip** is a separate discovery tool, not a crafting fix. Download and extract it on the game PC and run **Start-Diagnostic.cmd**. It guides one potion-batch test and saves **craft-report.json** locally. Only message types, sizes and timing counts are recorded; no packet contents or automatic uploads. Attach the report in the support chat. The normal app does not enable diagnostic recording.

Download **Aion2Presence-Setup.exe**, or use **Download and install** in the app. Exit the previous copy from the system tray before installing manually. Existing settings and the installation folder are retained.

Npcap, AION 2 and Discord desktop are required on the same computer. Matching source, notices and SHA-256 checksums are attached. The Windows executable remains unsigned.
