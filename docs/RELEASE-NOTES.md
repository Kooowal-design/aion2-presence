Public beta for Windows · English / Polski

## New in 0.2.0-beta.6

- New Aurora × Aether interface with original cyan artwork, glass panels and clearer character statistics.
- Compact 800 × 600 default window with larger labels, switches and buttons. Display choices are on the main screen; Help is available in the footer.
- Prominent green **Up to date** and gold **Update available** panels, with a manual check and checksum-verified installer download.
- English/Polish language switching, saved preferences, tray controls and feedback links are retained.
- The capture engine and activity detection are unchanged from beta.5, including dungeon/boss, crafting, gathering and nine Shugo competitions for both factions.

Download **Aion2Presence-Setup.exe**, or use **Download and install** in beta.5. When installing manually, exit the previous copy from its system tray menu first. Existing settings and the installation folder are retained. The normal executable uses live game data; the local design preview is not included in the release.

Npcap, AION 2 and Discord desktop are required on the same computer. If AION 2 reports a launch error, start the game before Presence. Matching source, notices and SHA-256 checksums are attached. The Windows executable remains unsigned.

## Polski

Nowy wygląd Aurora × Aether, kompaktowe okno 800 × 600, większe czcionki oraz czytelny panel stanu aktualizacji. Przełączniki znajdują się na ekranie głównym, a Pomoc na dole. Odczyt gry i wykrywane aktywności pozostają takie jak w beta.5.

Pobierz **Aion2Presence-Setup.exe** lub wybierz **Pobierz i zainstaluj** w beta.5. Przy instalacji ręcznej zakończ poprzednią kopię z menu ikony przy zegarku. Ustawienia i folder instalacji zostają zachowane. Jeśli gra zgłasza błąd przy uruchamianiu, włącz najpierw AION 2, potem Presence.
