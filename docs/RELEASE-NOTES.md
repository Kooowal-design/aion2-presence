Public beta for Windows · English / Polski

## New in 0.2.0-beta.12

- The idle activity line now reads **AION 2 - In game**, instead of repeating **AION 2** below the game title.
- Activity-only member-list mode uses the same descriptive idle text. Auto still shows selected stats while idle, and the fixed game-name mode remains **AION 2**.
- Recognized activities still show their own names. Normal in-game status has no small badge.
- All display choices, original artwork and capture behavior from beta.11 are retained.

Download **Aion2Presence-Setup.exe**, or choose **Download and install** in the app. For a manual update, exit the previous copy from its system tray menu first. Settings and the installation folder are retained.

**Polski:** Zwykła gra pokazuje teraz **AION 2 - In game** w linii aktywności profilu oraz w trybie samej aktywności na liście. Tryb automatyczny nadal pokazuje wybrane statystyki podczas zwykłej gry, a tryb samej nazwy gry pozostaje **AION 2**. Rozpoznane aktywności zachowują swoje nazwy.

Npcap, AION 2 and Discord desktop are required on the same computer. The executable remains unsigned. Matching source, notices and SHA-256 checksums are attached.
