# AION2 Presence branding

Selected concept: **Winged A**, option 1 from the icon comparison sheet.

- `logo.png`: generated master image, with transparency outside the navy tile.
- `app.ico`: Windows icon with 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 px frames.

The master was created with the built-in imagegen tool. The Windows container was encoded from that image without changing the design.

Generation prompt:

> Extract and carefully recreate ONLY concept 1 WINGED A from the provided comparison board as ONE finished square Windows application icon. The board is the reference, the first leftmost icon is the sole target. Preserve its identity closely: a sculpted silver capital A with icy cyan/blue mirrored upward wings, deep navy rounded-square tile, restrained bright bevel highlights, symmetric composition. Keep the same silver A proportions and wing silhouette. Make it a clean standalone 1024x1024 icon, tile occupying about 94% of canvas, central emblem generously large, crisp bold outlines visible at small sizes. Outside the rounded-square tile must be genuinely transparent alpha; inside tile remains deep dark navy. No extra margin, no labels, no numbers, no text, no other concepts, no comparison layout, no cast shadow beyond tile, no background scene. This is the final production app icon, not a mockup.
