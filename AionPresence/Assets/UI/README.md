# Aurora × Aether UI artwork

`background.png` and `wing.png` are original raster assets generated with the built-in image generation tool for this application. The approved Aurora × Aether mockup and the project's winged A logo were used as visual references. The wing includes a real alpha channel. UI text, cards, buttons, toggles and values are native WPF controls; they are not flattened into these images.

The exact generation prompts are in `prompts.json`.
