# Discord artwork

Original class icons and activity badges created for AION2 Presence with the built-in image generation tool. The project logo was the style reference. Exact prompts are in `prompts.json`.

- `class/`: nine class designs; Gladiator uses one two-handed greatsword; Sorcerer uses an open spellbook. The Brawler design is prepared for supported game versions.
- `activity/`: boss, dungeon, crafting, gathering and Shugo. The Shugo badge uses a stylized face.
- There is deliberately no idle / in-game badge.

These are Discord activity images, not replacements for the online/idle/DND indicator beside a user's avatar. Assets are hosted in the project repository at the release tag specified by `discord-app.json`. They do not require loading any artwork from another tool's Discord application.
